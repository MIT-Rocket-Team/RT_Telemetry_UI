# Zephyrus test flight

Lossless copies of the user's `ZEPH_TEST_FLIGHT_GS1.csv`, `GS2.csv` and `GS3.csv`
recordings. See `docs/DEMO_DATA.md` for provenance, timing and quality notes.
`manifest.json` hashes refer to the original **uncompressed** bytes. The application
checks each selected log's hash before starting playback. GS2 is the default.
