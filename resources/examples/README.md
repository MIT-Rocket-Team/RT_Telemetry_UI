# Included examples

`simple.ork` is OpenRocket's “A simple model rocket” example, copied from the user-provided fork for repeatable packaging tests. It is a small example model, not the team's controlled rocket. OpenRocket GPL notice: `docs/licenses/OpenRocket-GPL.txt`.

`illustrative-trajectory.csv/.json` and `example-mission.json` are synthetic examples generated by this application's deterministic demonstration. Their launch coordinates are deliberately unset; mission loading never restores pointer calibration.
